2. IR Devices

A registry of named IR commands per physical device — works fully offline, no Harmony hub, no Home Assistant, no cloud. Used by scene_grid tiles (IR device + command) and by Activities' IR-sourced devices below.
Must match exactly what you copied into /sdcard/astrion/ir-database/ on the remote — the app resolves the actual commands from that file at runtime, this builder never touches ir-database/ itself.

3. Activities

A composed AV Activity ("Watch Apple TV", "Listen to Music"...) that orchestrates more than one device, mixing IR/Harmony/HA freely. Scoped to one room — at runtime, only one Activity is active per room at a time. For a single-device/single-action Activity (one HA script, one existing Harmony Activity), you don't need this section — just tick "Track as Activity" on a scene_grid tile instead.
